# Majstori Pazova

Imenik majstora (struja, voda, krečenje, keramika...) za opštinu Stara Pazova.

- Filter po mestu (Stara Pazova, Nova Pazova, Banovci, Golubinci...)
- Poziv majstora jednim klikom
- Ocene i recenzije

## Stanje

Prototip: majstori, ocene i brojevi telefona su izmišljeni. Ocene se zasad čuvaju samo u pregledaču.

## Plan

- Firebase (Firestore) za majstore i ocene, da ocene vide svi korisnici
- Prijava preko Google naloga (SMS kasnije)
- Objava na Netlify

## Pokretanje

Otvori `index.html` u pregledaču. Ništa ne treba instalirati.
